# 最終回答の構成

見出しの順番は固定する。
各節は短く書き、長くなる根拠は根拠表への参照で済ませる。

```
## 結論
<1〜2文。何をどうすべきか、もしくは問いへの答え>
確信度：<高・中・低>（<理由1文>）

## 根拠
① <根拠1>（出典）
② <根拠2>（出典）
③ <根拠3>（出典）

## 検討して採らなかった案
① <案B>：<採らなかった理由1文>
② <案C>：<採らなかった理由1文>

## リスク・留保
<反論のうち、結論は変えないが残るもの。未確認事項>

## 相談したいこと
<consultation-template.md の形式。なければ「なし」>

## 次にやること
① <誰が・何を・いつまでに>
```

## 書き分け

チャットでの短い質疑応答では「結論」「根拠」「相談したいこと」の3節だけにしてよい。
ドキュメントとして渡す場合は全節を書き、末尾に根拠表を付録として付ける。
メール文にする場合は、結論と相談したいことを本文に書き、根拠は箇条で3つまでにする。
