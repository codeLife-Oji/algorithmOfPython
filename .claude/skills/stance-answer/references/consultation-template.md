# 相談メモの書式

相談事項は1件ごとに次の形で書く。
相談相手が、このメモだけを読んでその場で選べることを目標にする。

```
相談1：<何を決めてほしいかを1文で>

相談相手：<名前、もしくは役割。不明なら「要確認」>
なぜ相談するか：<Phase 5 の①〜④のどれに当たるか、と具体的な理由>
結論への影響：<この答えで最終回答のどこが変わるか>
選択肢：
  ① <選択肢A>：<選んだ場合に起きること>
  ② <選択肢B>：<選んだ場合に起きること>
AIの推奨：<①か②か、と理由1文>
決まらない場合の暫定対応：<期限までに回答がないときにAIが仮置きする内容>
必要な時間の目安：<5分で済むか、打ち合わせが要るか>
```

## 例

```
相談1：稼働目標を12月と3月のどちらにするか決めてください。

相談相手：プロジェクト責任者
なぜ相談するか：④に該当。見積書は3月、9/5議事録は12月で食い違っており、社外との約束に関わる。
結論への影響：12月なら案Bは不可能になり、推奨が案Aに変わる。
選択肢：
  ① 12月稼働：機能を半分に絞る必要がある
  ② 3月稼働：全機能を入れられるが、年内の成果報告はできない
AIの推奨：②。見積書が議事録より後の日付で、ベンダーとの合意に近い。
決まらない場合の暫定対応：②を前提に資料を作り、12月案の差分を付録に付ける。
必要な時間の目安：5分（選ぶだけ）
```

## 相談にまとめる時間の作り方

相談事項が3件以上ある場合は、1回の打ち合わせでまとめて聞く。
その場合は相談メモの先頭に次の2行を付ける。

① 打ち合わせで決めたいこと（件数と、全体で何分必要か）
② 事前に読んでほしい資料（ファイル名かURL）
